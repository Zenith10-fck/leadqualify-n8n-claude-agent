03

The reliability layer

Fails loudly, never silently

Most AI integrations work fine on the first fifty runs, then start returning JSON in a slightly different shape and break downstream without anyone noticing. I build against exactly that failure mode.

Every Claude response is validated against a strict schema (types, enums, ranges, required fields). On drift the workflow re-prompts once with the exact error. If it still fails, the lead routes to a human with a Slack alert. A malformed AI response can never create a half-shaped contact or swallow a real lead.
